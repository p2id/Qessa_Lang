# المواصفة الرئيسية لـ Qessa (MASTER_SPEC)

هذه الوثيقة هي المرجع الوحيد. تتعارض معها الوثائق القديمة في `docs/` إلى أن تُحدَّث، وعند التعارض تُعتمد هذه الوثيقة.

## 1. الرؤية
لغة برمجة هجينة ومترجم يولّد ملفات تنفيذية مباشرة دون assembler أو linker خارجي. أساسها لغة عامة (**Core**) تُشتق منها profiles بحسب الحاجة. القرار D-001.

## 2. الأهداف غير القابلة للتفاوض
1. لا silent fallback في أي مرحلة: المجهول يُرفض بتشخيص.
2. لا ملف تنفيذي جزئي عند فشل الترجمة.
3. لا ادعاء دعم ميزة غير مختبرة تشغيليًا على كل مترجم ومنصة معلنين لها.
4. لا إصدار قبل اجتياز كل بوابات القبول (D-007، D-010).
5. كل تغيير سلوك يمر عبر المواصفة والاختبارات.

## 3. مفهوم Core وProfiles (مقترح تصميميًا، ينتظر OQ-6)
| Profile | الذاكرة | الأنواع | الغرض |
|---|---|---|---|
| `core` | تلقائية ذكية (افتراضي) | تدريجية | الاستخدام العام |
| `systems` | يدوية كاملة + regions | اختيارية، يُشجَّع عليها | تحكم دقيق وواجهات النظام |
| `managed` | تلقائية بالكامل | مُتحقق منها أكثر | برمجيات أعلى مستوى |
التبديل: يدوي من المبرمج (على مستوى وحدة/دالة)، أو تحويل تلقائي يقرره المترجم عندما يثبت أمانه. صياغة التبديل لم تُحسم (OQ-6).

## 4. نطاق الإصدار الأول (D-011)
كل ميزات الرؤية: الدوال، المتغيرات والثوابت والنطاقات وshadowing، الأعداد الصحيحة والعشرية، النصوص والمحارف وbool وnull، المصفوفات، المؤشرات، structs، enums، tuples، methods، generics، closures، macros، pattern matching، modules وuse، extern، regions، معالجة الأخطاء، المكتبة القياسية وI/O وsyscalls. لا تُحذف ميزة منها إلا بقرار مسجل في `DECISIONS.md`.

## 5. المنصات المستهدفة (D-003)
| المنصة | الحاوية | الحالة الحالية |
|---|---|---|
| Linux x86-64 | ELF | موجودة، مختبرة جزئيًا |
| Linux ARM64 | ELF | غير موجودة |
| macOS | Mach-O (المعمارية: OQ-1) | غير موجودة |
| Windows | PE (المعمارية: OQ-1) | غير موجودة |

## 6. أدوات المطور (D-008)
مواضع أخطاء دقيقة، Formatter، Linter، REPL، Debugger، LSP ودعم محرر، مدير حزم.

## 7. المعالم الداخلية (غير معلنة كإصدارات)
M0 خط الأساس، M1 السلامة P0، M2 الواجهة الأمامية الموحدة والتشخيصات، M3 الميزات الأساسية، M4 الميزات المتقدمة والأنواع التدريجية، M5 الذاكرة التلقائية، M6 backends، M7 الأدوات، M8 التحقق والتوزيع والإصدار. التفاصيل في `ROADMAP.md`.
