# مواصفات Qessa الأولية

هذه مواصفات عملية مستخلصة من الشجرة الحالية والأمثلة، وليست عقدًا لغويًا نهائيًا. دعم الصياغة أو وجود فرع في AST لا يعني بالضرورة اكتمال دلالته أو سلامته وقت التشغيل.

## منصة التنفيذ

| البند | الحالة المثبتة |
|---|---|
| نظام التشغيل | Linux |
| المعمارية | x86-64 |
| الناتج | ELF تنفيذي يُصدره المترجم مباشرة |
| ABI المدخل | `main` مع تمرير `argc` و`argv` |
| bootstrap | stage-1 Rust → stage-2 selfhost → stage-3 selfhost؛ تطابق stage-2/3 byte-for-byte؛ 8 أمثلة subset تتطابق مخرجاتها عبر كل المراحل |

## عناصر اللغة

تضم الشجرة دوالًا ومعاملات وقيمًا معادة، ومتغيرات `let`، وثوابت، وكتلًا وشروط `if/else`، وحلقات `while` و`for`، و`break` و`continue` و`return`. تشمل التعبيرات الأعداد الصحيحة والعشرية والسداسية، السلاسل والمحارف والمنطقية و`null`، الاستدعاءات والمصفوفات والفهرسة والمؤشرات والعمليات الحسابية والمقارنة والمنطقية والبتية والإسناد المركب.

تُقبل الفاصلة المنقوطة كفاصل جمل، وقد اختُبر ذلك في `examples/test_final.qs`. كما اختُبر parsing لتعبير `new Widget()`، لكن ذلك **ليس إثباتًا كافيًا** على تخصيص الأنواع أو دلالة `new` الكاملة.

لا يوجد هنا مرجع رسمي مكتمل لأسبقية العمليات، أو التحويلات النوعية، أو نطاق المتغيرات، أو تجاوز الأعداد، أو القسمة على صفر، أو حدود المصفوفات، أو ملكية المؤشرات. يلزم تثبيت هذه القواعد قبل وصف اللغة بأنها مستقرة.

### تغطية التنفيذ الذاتي

اختُبرت stage-1/2/3 على `arrays`, `factorial`, `full_test`, `hello`, `pointers`, `recursion`, `simple_loop`, و`test_final`، وتطابقت المخرجات مع Rust CLI. النسخة الذاتية ترفض حاليًا أمثلة `comprehensive`, `enums`, `modules`, `regions`, و`structs` برسائل parse errors ولا تصدر executable. هذا قيد خاص بتنفيذ selfhost الحالي، وليس حكمًا على قبول Rust compiler لتلك الأمثلة.

## CLI

```text
qessac compile <input.qs> [-o <output>] [--no-stdlib]
qessac run [--no-stdlib] <input.qs> [program args...]
qessac tokens <input.qs>
qessac ast <input.qs>
qessac asm <input.qs>
```

تُضمّن stdlib في أوامر `compile` و`run` افتراضيًا. يمرر `run` الوسائط اللاحقة إلى البرنامج الناتج ويعيد رمز خروجه. يرفض `compile` مصدرًا بلا `fn main`، كما يُبلغ عن الدوال والمتغيرات والـ syscalls غير المعرفة. الربط برمز خارجي غير syscall غير مدعوم في ELF الثابت الحالي.

## المكتبة القياسية

تحتوي `src/qessac/stdlib.qs` على دوال مثل `strlen` و`strcmp` و`memcpy` و`alloc_bytes` و`read_file` و`write_file`، ومخازن ديناميكية وواجهات ذاكرة. اختُبر `read_file` على مدخل يتجاوز 1 MiB. لا يعني ذلك اكتمال عقود الأخطاء أو استرجاع الذاكرة أو كل حالات I/O.

## قيود معلومة

- bootstrap اجتاز harness على Linux x86-64؛ لم يُختبر بعد على corpus واسع أو منصة أخرى، فلا يعني اكتمال اللغة أو ضمان كل البرامج.
- يوجد اختلاف بين backendين: Rust يعرّف 45 syscall names، بينما selfhost يعرّف 7 فقط؛ والأشد أن selfhost يحوّل الاسم المجهول حاليًا إلى `syscall_exit` بدل رفضه. لا تستخدم syscall غير معروفة حتى إصلاح هذا السلوك.
- region allocator مخصص لمساحة 1 MiB؛ حدود bump allocation ونتائج فشل `mmap` تحتاج فحوصًا واختبارات إضافية قبل الاعتماد على تخصيص غير محدود.
- التحذيرات في build قائمة: 22 تحذيرًا غير قاتل في آخر تشغيل cargo test.
- لا يوجد إثبات لدعم macOS أو ARM أو مكتبات خارجية أو أدوات REPL/debugger/LSP.
- لا ينبغي اعتبار أي ميزة غير مدرجة ضمن الاختبارات الناجحة مدعومة إنتاجيًا لمجرد وجودها في AST أو source.
