# مواصفة اللغة (LANGUAGE_SPEC)

**الحالة:** مسودة. الحالة `OBSERVED` = ما يفعله المنفذ الحالي (قرأته في الشيفرة). `PROPOSED` = اقتراحي لعقد جديد ينتظر موافقة. `OPEN` = غير محسوم. لا شيء هنا `APPROVED` بعد باستثناء القرارات في `DECISIONS.md`.
ملاحظة: المرجع الأصلي للغة (v0.1) غير متوفر (OQ-3)، فالنحو أدناه مستخلص من الوثائق والأمثلة ولم أراجعه ضد مرجع.

## 1. العناصر الموجودة نحويًا (OBSERVED، من الوثائق وAST)
دوال بمعاملات وقيم معادة، `let` وثوابت، `if/else`، `while` و`for`، `break`/`continue`/`return`، أعداد صحيحة وعشرية وسداسية، سلاسل ومحارف وbool وnull، استدعاءات، مصفوفات وفهرسة، مؤشرات، عمليات حسابية ومقارنة ومنطقية وبتية وإسناد مركب، فاصلة منقوطة اختيارية، `new T()` (تحليل فقط).

## 2. عقد مقترح للحالات الحدية (PROPOSED، يحتاج موافقة)
| الحالة | السلوك المقترح |
|---|---|
| تجاوز الأعداد الصحيحة (`i64`) | wraparound بالمتمم الثنائي، موثّق. وملف إعداد لاحق لـ checked arithmetic في وضع debug |
| القسمة على صفر و`INT64_MIN / -1` | trap وقت التشغيل: رسالة على stderr ورمز خروج 134 |
| إزاحة بقيمة خارج 0..63 | trap |
| فهرس مصفوفة خارج الحدود | trap برسالة. الاستثناء: وضع `systems` غير المفحوص صراحةً |
| `null` | القيمة 0، لا يمكن إلغاء مرجعيته (trap) |
| مؤشر غير صالح | سلوك غير معرّف في `systems` فقط. في `core`/`managed` مرفوض |
| shadowing | يُسمح داخل كتلة أعمق ويحل الاسم إلى أحدث تعريف مرئي. إعادة التعريف في النطاق نفسه خطأ ترجمة (OBSERVED الآن: lookup الأحدث؛ تكرار النطاق غير محسوم) |
| تعريف `main` | مطلوب ومفرد (OBSERVED) |
| ميزة غير مدعومة | خطأ ترجمة بتشخيص `unsupported feature` وموضعه، لا قيمة افتراضية |

## 3. الأسبقية والترابط
**OPEN:** لا جدول أسبقية رسمي في الوثائق. المطلوب أن يُستخرج من parser ثم يُجمَّد باختبارات golden. لا أقدّم جدولًا من التخمين.

## 4. الأنواع (D-004)
- الافتراضي: ديناميكي. الأنواع الاختيارية: `x: int` ونحوها، يتحقق منها المترجم عند التصريح بها. صياغتها: **OPEN** (OQ-6).
- التحويلات الضمنية بين int وfloat وbool: **OPEN**، تحتاج قرارًا.

## 5. الميزات المتقدمة: حالتها الفعلية وما ينقص
| الميزة | الحال الآن (OBSERVED) | المطلوب |
|---|---|---|
| structs / enums / modules / regions | تُقبل وتعمل في Rust في أمثلة المشروع | دعم selfhost + عقد دلالات + اختبارات سلبية |
| match | تُحلل؛ Rust يولّد 0 بصمت | دلالات pattern كاملة، فحص الاكتمال، destructuring |
| closures | تُحلل؛ Rust يولّد 0 بصمت | capture وبيئة وعمر |
| macros | تُحلل؛ sema يعلن أنها stub | تصميم نظام macros (hygienic أم لا: OPEN) وتوسيعها قبل sema |
| generics | تُحلل فقط | تصميم: monomorphization أم dispatch ديناميكي (OPEN، يتأثر بـ D-004) |
| floats | تُخزَّن bits في i64 | عمليات SSE/FPU والتحويلات |
| methods | تُحول إلى `__method_<n>` | نظام dispatch موثق |
| extern / use | extern غير syscall مرفوض في ELF الساكن | تصميم ربط لكل منصة (Windows/macOS تحتاج مكتبات النظام) |

## 6. أمثلة يجب رفضها (اختبارات سلبية مطلوبة)
```
fn main() { return y }             // معرّف مجهول → خطأ ترجمة
fn main() { syscall_nope(1) }      // syscall مجهول → خطأ ترجمة
fn main() { foo() }                // دالة مجهولة → خطأ ترجمة
fn f() {} fn f() {}                // تكرار تعريف → خطأ
let x = match 1 { _ => 2 }         // يجب أن ينتج نتيجة صحيحة أو خطأ unsupported، لا 0 صامتة
```
كل مثال يجب أن يفشل على Rust وstage-1 وstage-2 وstage-3 بالطريقة نفسها وبلا ملف ناتج.
