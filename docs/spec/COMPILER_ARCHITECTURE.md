# معمارية المترجم (COMPILER_ARCHITECTURE)

## 1. الحالة الحالية (OBSERVED)
Source → Lexer (738 سطرًا) → Parser (1,065) → AST (311) → Sema (267) → Codegen (1,129 + mach 447) → Emit/ELF (791) → CLI (336). المترجم الذاتي (`qessac.qs`، 2,842 سطرًا) يُعيد تنفيذ المراحل في ملف واحد بـ 27 نوع عقدة AST فقط، ولا أرى فصلًا واضحًا لـ sema فيه (لم أراجع الملف كله بعد).

## 2. أسباب إعادة التصميم الموضعية (D-006)، كلها مثبتة بقراءة الشيفرة
| المكوّن | الدليل | التغيير المقترح |
|---|---|---|
| جدول syscall | نسختان مستقلتان: 45 مقابل 7؛ المجهول → exit في selfhost | مصدر واحد `syscalls.def` لكل منصة، يولَّد منه جدول Rust وملف `.qs`، مع اختبار توافق يفشل عند الاختلاف |
| غياب sema موحد | selfhost يترجم معرّفًا/دالة مجهولة بصمت | تحقق دلالي إلزامي قبل codegen في selfhost، وbarrier: codegen لا يعمل إن وُجد خطأ |
| codegen بقيم افتراضية | `Match/Closure/MacroCall → 0` في Rust | كل عقدة غير منفذة ⇒ خطأ `unsupported` (قاعدة: `match` شاملة بلا `_ =>` افتراضي) |
| runtime التخصيص | لا فحص حد؛ تعليقات تقر بـ bug في حساب الطول | إعادة كتابة `__alloc_array` مع checked arithmetic وفحص حد وفشل `mmap` |
| ربط ISA بالحاوية | codegen x86-64 مرتبط بـ ELF والـ syscall ABI الخاص بـ Linux | فصل ثلاث طبقات (انظر 3) |

## 3. البنية المستهدفة للمنصات (D-003)
```
Frontend (lexer/parser/AST/sema/types)     ← واحد لكل المنصات
        ↓  IR وسيط (مقترح، يحتاج موافقة)
Backend ISA:   x86_64  |  aarch64
OS ABI layer:  linux   |  macos   |  windows     (syscalls/استيراد/نقطة الدخول/الاستدعاء)
Container:     ELF     |  Mach-O  |  PE
```
- **مخاطر معروفة:** Windows لا يوفر syscalls مستقرة، فيحتاج جدول استيراد لـ kernel32/ntdll داخل PE (يتعارض مع «ELF ساكن بلا ربط»). macOS يتطلب توقيع الشيفرة على Apple Silicon وAPI نظام عبر libSystem في الغالب. هذان قراران معماريان يحتاجان موافقتك قبل التنفيذ.
- إدخال IR وسيط تغيير كبير. بدونه سيتضاعف الكود لكل ISA. أطلب موافقة صريحة عليه.

## 4. عقود الطبقات
- Lexer: يعيد رموزًا بمواضع (سطر، عمود، بداية، نهاية) أو خطأ. لا panic على أي بايتات.
- Parser: يعيد AST صحيحًا أو أخطاء بمواضع؛ لا يقبل صياغة لا يعرف دلالتها.
- Sema: يرفض المجهول والتكرار وتدفقات التحكم غير الصالحة؛ ويحمل الأنواع الاختيارية.
- Codegen: لا يُصدر إلا لعقد مدعومة. أي خطأ ⇒ لا ناتج.
- Emit: كتابة ذرية (ملف مؤقت ثم rename)، صلاحيات segments W^X.
- CLI: رموز خروج ثابتة، لا كتابة فوق ملف غير مقصود.
- Runtime/stdlib: عقد خطأ موحد (انظر `MEMORY_AND_ABI.md`).
